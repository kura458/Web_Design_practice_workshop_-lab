\# Flappy Penguin



A cartoon penguin illustration created using HTML and CSS as part of my freeCodeCamp Responsive Web Design practice.



\## Features

\- Penguin character built from HTML elements and CSS shapes

\- CSS gradients for the sky, mountains, and character

\- Animated waving arm using CSS keyframes

\- Interactive scaling effect when clicking the penguin

\- CSS custom properties for reusable colors

\- Layered scenery using positioning and z-index



\## Technologies

\- HTML5

\- CSS3



\## Concepts Practiced

\- CSS positioning

\- Linear gradients

\- Border radius and geometric shapes

\- CSS transforms and transform origins

\- Keyframe animations

\- CSS transitions

\- Pseudo-elements

\- CSS custom properties

\- Viewport units and calculations



\## How to Run

Open `index.html` in a web browser.
