\# Cat Painting



A CSS art project that creates a cat's face using HTML and CSS.



\## Features

\- Cat head and ears

\- Inner ears and eyes

\- Nose and mouth

\- Left and right whiskers

\- CSS positioning, borders, transforms, and gradients



\## Technologies

\- HTML5

\- CSS3



\## How to Run

1\. Download or clone this project.

2\. Open `index.html` in a web browser.
