# SoundWave — Wireless Headphones Landing Page

A responsive product landing page for fictional SoundWave wireless headphones, created with HTML5 and CSS3 as part of my freeCodeCamp Responsive Web Design practice.

## Features
- Fixed header with navigation links
- Product feature cards
- Embedded YouTube product demonstration
- Three pricing plans
- Email subscription form
- Responsive mobile layout
- Hover transitions and smooth scrolling

## Technologies
- HTML5
- CSS3
- YouTube embedded video

## Concepts Practiced
- Semantic HTML elements
- Flexbox layouts
- CSS gradients and transitions
- Fixed positioning
- Responsive media queries
- HTML forms and email validation
- Embedded multimedia
- CSS selectors and reusable classes

## How to Run
Open `index.html` in a web browser. An internet connection is required for the external logo and embedded YouTube video.
