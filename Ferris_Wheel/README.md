\# Ferris Wheel



A Ferris Wheel animation built with HTML5 and CSS3 as part of my freeCodeCamp Responsive Web Design practice.



\## Features

\- Rotating Ferris Wheel

\- Six cabins positioned around the wheel

\- Animated cabin colors

\- Smooth, continuous CSS animations

\- Responsive wheel sizing



\## Technologies Used

\- HTML5

\- CSS3



\## Concepts Practiced

\- CSS animations and keyframes

\- CSS transforms and rotation

\- Absolute positioning

\- CSS pseudo-class selectors

\- Responsive sizing with viewport units

\- Animation timing functions



\## How to Run

Open `index.html` in a web browser.
