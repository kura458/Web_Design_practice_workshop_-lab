# Web Design Practice Workshop

A collection of HTML and CSS practice exercises and small frontend projects completed while studying responsive web design and frontend development.

This repository brings together individual exercises, page layouts, forms, visual components, and interactive interface examples. It is intended as a learning portfolio that shows practice with semantic HTML, CSS styling, layout, and accessibility fundamentals.

## What You'll Find

The repository includes practice work covering:

- **Forms and user input:** contact forms, registration forms, surveys, donation forms, job applications, and feedback forms.
- **Page layouts and content:** book inventory, book catalog, blog posts, newspaper layouts, tribute pages, and documentation pages.
- **CSS illustrations and visual effects:** cat painting, city skyline, ferris wheel, moon orbit, piano, markers, and other styled components.
- **Interactive interface exercises:** media players, settings panels, planners, and other UI-focused projects.
- **Accessibility practice:** accessible quizzes and interface components.

Many exercises are stored in their own folders. Some standalone HTML and CSS exercises are also located in the repository root.

## Technology

- HTML5
- CSS3
- Responsive layout techniques
- Semantic markup and accessibility fundamentals

## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/kura458/Web_Design_practice_workshop_-lab.git
   ```

2. Open the repository folder in your code editor.
3. Open the HTML file for the exercise you want to view in a browser.

For example, open `Book_Inventory/index.html` to view the Book Inventory exercise.

No package manager or build step is required for these standalone HTML/CSS exercises.

- Write semantic and well-structured HTML.
