\# Moon Orbit



A simple animated Earth and Moon orbit demonstration built with HTML and CSS as part of my freeCodeCamp web development practice.



\## Features

\- Earth and Moon illustrations using CSS

\- Circular orbital path

\- Continuous moon orbit animation

\- Radial gradients and glowing effects

\- Responsive full-screen layout

\- Reduced-motion accessibility support



\## Technologies

\- HTML5

\- CSS3



\## Concepts Practiced

\- CSS positioning

\- Flexbox

\- CSS transforms

\- Keyframe animations

\- Linear and radial gradients

\- Border radius

\- Media queries

\- Accessibility preferences



\## How to Run

Open `index.html` in a web browser.
