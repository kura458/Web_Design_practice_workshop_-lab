\# Piano



A piano keyboard layout created with HTML and CSS as part of my freeCodeCamp Responsive Web Design practice.



\## Features

\- Piano body with a green background

\- White piano keys

\- Black keys created using CSS pseudo-elements

\- freeCodeCamp logo

\- Responsive layout for different screen widths



\## Technologies

\- HTML5

\- CSS3



\## Concepts Practiced

\- CSS box model

\- Positioning and floating elements

\- Pseudo-elements (`::after`)

\- Media queries

\- Responsive web design



\## How to Run

Open `index.html` in a web browser.
