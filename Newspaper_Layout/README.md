# The Daily Chronicle — Newspaper Layout

A newspaper-style webpage built with HTML5 and CSS3 as part of my freeCodeCamp Responsive Web Design practice.

## Features
- Newspaper-inspired layout
- CSS Grid with named grid areas
- Featured and secondary articles
- Cover image with alternative text
- Three smaller news articles
- Classic newspaper typography and styling

## Technologies Used
- HTML5
- CSS3

## Concepts Practiced
- Semantic HTML elements
- CSS Grid
- Grid template areas
- CSS box model
- Typography and spacing
- Image styling
- Responsive image sizing

## How to Run
Open `index.html` in a web browser.
