

\# Tribute Page — Dr. Norman Borlaug



A responsive tribute page created as part of my freeCodeCamp web development practice.



\## About

This project honors Dr. Norman Borlaug, an agricultural scientist recognized for his contributions to improving food production and fighting hunger.



\## Features

\- Responsive page layout

\- Image and caption

\- Biography and achievements

\- External Nobel Prize biography link

\- Custom CSS styling



\## Technologies

\- HTML5

\- CSS3



\## How to Run

1\. Clone or download the repository.

2\. Open `index.html` in your web browser.

3\. Make sure you have an internet connection to load the external image.



\## Learning Goals

Practice semantic HTML, CSS selectors, responsive design, image styling, and external links.
