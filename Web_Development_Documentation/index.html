HTML Basics

HTML stands for HyperText Markup Language.

It provides the structure and content of a web page.

A basic HTML document starts with a doctype declaration.

<!DOCTYPE html>
  • HTML uses elements to organize content.
  • Elements are written using tags.
HTML Elements

HTML elements represent different types of content.

Most elements have an opening tag and a closing tag.

<p>Hello world!</p>

Headings describe the importance of page content.

<h1>Main Heading</h1>
  • Paragraphs contain text.
  • Links connect pages and resources.
CSS Basics

CSS stands for Cascading Style Sheets.

It controls the appearance of HTML elements.

p { color: blue; }

CSS can change colors, spacing, sizes, and layouts.

  • External CSS keeps styles separate from HTML.
  • CSS rules contain selectors and declarations.
CSS Selectors

Selectors determine which HTML elements receive styles.

An element selector targets elements by their tag name.

h1 { font-size: 2rem; }

A class selector starts with a period.

.card { padding: 1rem; }

An ID selector starts with a hash symbol.

#navbar { background-color: black; }
  • Class selectors can match multiple elements.
  • ID selectors identify a specific element.
Responsive Design

Responsive design helps websites adapt to different screen sizes.

Media queries apply styles under specific conditions.

@media (max-width: 600px) { body { font-size: 14px; } }

Flexible layouts improve usability on mobile devices.

  • Use the viewport meta tag.
  • Test layouts on different screen sizes.
  • Use flexible widths when appropriate.
