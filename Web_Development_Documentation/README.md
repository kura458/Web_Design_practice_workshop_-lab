\# Web Development Documentation



A technical documentation page introducing HTML, CSS, CSS selectors, and responsive web design.



\## Features

\- Fixed navigation sidebar on desktop

\- Navigation links to five documentation sections

\- Code examples and explanatory text

\- Responsive layout for smaller screens

\- Hover and keyboard-focus styles for navigation links



\## Technologies

\- HTML5

\- CSS3



\## Concepts Practiced

\- Semantic HTML

\- CSS positioning and selectors

\- Navigation links and section IDs

\- Media queries

\- Responsive layouts

\- Code formatting



\## How to Run

Open `index.html` in a web browser.
