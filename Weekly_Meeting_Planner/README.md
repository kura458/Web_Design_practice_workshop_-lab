\# Weekly Meeting Planner



A responsive weekly meeting availability schedule built with HTML5 and CSS3 as part of my freeCodeCamp Responsive Web Design practice.



\## Features

\- Weekly schedule from Monday to Friday

\- Color-coded meeting availability levels

\- Availability legend with a CSS gradient

\- Accessible table headers and labels

\- Responsive layout for smaller screens

\- Solid and dashed row borders



\## Technologies Used

\- HTML5

\- CSS3



\## Concepts Practiced

\- Semantic HTML tables

\- CSS custom properties

\- CSS gradients

\- CSS selectors and classes

\- Media queries

\- Responsive design

\- Accessibility attributes



\## How to Run

Open `index.html` in a web browser.
