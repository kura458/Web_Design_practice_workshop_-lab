\# Newspaper Article



A newspaper-style article page built with HTML and CSS as part of my freeCodeCamp practice.



\## Features

\- Newspaper name and publication date

\- Main headline and subheadline

\- Author information

\- Article paragraphs with indented text

\- Enlarged, bold first letters

\- Centered newspaper layout



\## Technologies

\- HTML5

\- CSS3



\## Concepts Practiced

\- CSS font sizing and typography

\- Text alignment and transformation

\- Margins and padding

\- Relative units such as `rem` and `em`

\- The `::first-letter` pseudo-element



\## How to Run

Open `index.html` in a web browser.
