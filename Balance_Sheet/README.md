\# Balance Sheet



A responsive balance sheet built with HTML and CSS as part of my freeCodeCamp practice.



\## Features

\- Assets, liabilities, and net worth tables

\- Financial data for 2019, 2020, and 2021

\- CSS styling for totals and current-year values

\- Hover effects for total rows

\- Accessibility support using screen-reader-only text

\- Sticky year headings



\## Technologies

\- HTML5

\- CSS3



\## How to Run

1\. Open the project folder.

2\. Open `index.html` in a web browser.
