# Book Inventory

A responsive book inventory table built with HTML5 and CSS3 as part of my freeCodeCamp Responsive Web Design practice.

## Features
- Displays book titles, authors, categories, and reading statuses
- Color-coded rows for different reading statuses
- Visual three-circle book ratings
- Responsive styling for smaller screens
- Gradient backgrounds and styled table headers

## Technologies
- HTML5
- CSS3

## Concepts Practiced
- Semantic HTML tables
- CSS selectors and attribute selectors
- CSS gradients
- Inline-block elements
- Pseudo-classes and child selectors
- Responsive design with media queries

## How to Run
Open `index.html` in a web browser.
