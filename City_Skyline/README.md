\# City Skyline



A city skyline illustration created with HTML and CSS as part of my freeCodeCamp Responsive Web Design practice.



\## Features

\- Background and foreground buildings

\- CSS-generated windows and architectural shapes

\- Day and night color themes

\- Responsive design using media queries

\- CSS gradients for the sky and building details

\- Reusable CSS custom properties



\## Technologies

\- HTML5

\- CSS3



\## Concepts Practiced

\- CSS Flexbox

\- Absolute and relative positioning

\- Linear and radial gradients

\- Repeating gradients

\- CSS custom properties

\- Responsive media queries



\## How to Run

Open `index.html` in a web browser and resize the window to see the day-to-night effect.
